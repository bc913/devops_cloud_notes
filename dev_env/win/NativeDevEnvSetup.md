# Native (C/C++) Development Environment Setup

## Installations
- C/C++ Compiler
    - Windows
        1. MSVC Compiler (2019 or 2022) -> refer to bat files under dev_env folder
    - Linux
        1. GCC and G++ compilers (version 11.0)
    - Mac
        1. Clang
- CMake 
    - [3.25.3](https://github.com/Kitware/CMake/releases/tag/v3.25.3)
    - Make sure it is added to PATH

- Git
    - Windows
        - Install [Git for Windows](https://gitforwindows.org/)
        - https://github.com/git-ecosystem/git-credential-manager/blob/release/docs/install.md
        - This will also install Git Credentials Manager which is to be used for storing Github credentials
